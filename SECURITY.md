# Security Policy

## Supported Versions

Security updates are provided for the latest official release of the
WEDA frontend.

Unofficial forks and modified distributions are not supported.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub
issues, discussions, or pull requests.

Report vulnerabilities using GitHub Private Vulnerability Reporting
("Report a vulnerability" on this repository's Security tab). If that is
unavailable, contact us through the official WEDA website:

https://learn.advantech.com/zh-tw/weda/docs/Introduction/

Please include enough information to reproduce and evaluate the issue,
such as the affected version, reproduction steps, and potential impact.

## Scope

This policy applies to the WEDA frontend source code and official
releases maintained by Advantech.

Third-party deployments, modified distributions, and unrelated
third-party services are outside the scope of this policy.
